# iSpring — тестовое задание аналитика

Репозиторий содержит решение первой задачи тестового задания аналитика iSpring: проектирование реляционной базы данных онлайн-магазина и разработка SQL-отчёта по продажам.

## Структура проекта

- `1_первая_версия/` — первоначальная версия проекта и последовательные изменения.
- `2_финальная_версия/` — итоговая версия проекта, SQL-запросы и автоматические тесты.
- `.github/workflows/` — настройки автоматического тестирования с помощью GitHub Actions.

## Реализовано

- Проектирование схемы БД онлайн-магазина.
- SQL-запрос для отчёта по продажам в разрезе месяцев, товарных групп и товаров.
- Подготовка тестовых данных.
- Проверка ограничений целостности и корректности отчёта.
- Автоматический запуск тестов через GitHub Actions.

## Запуск проекта

Подробная инструкция находится в [README финальной версии](2_финальная_версия/README.md).

## Ограничения

Выполнена только задача 1 исходного задания. Статистический анализ клиентской выборки и визуализация результатов не реализованы.
